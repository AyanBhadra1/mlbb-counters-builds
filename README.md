# MLBB Counters & Builds

A fan-made Mobile Legends: Bang Bang guide: hero counters, anti-counter chains
for solo, duo, trio and squad play, builds for all five lanes, and pick-rate /
win-rate graphs. Updated by hand every Thursday at 4:00 PM Dhaka time.
